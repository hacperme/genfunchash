# GenFuncHash 设计文档

## 项目概述

GenFuncHash 是一个用 Rust 语言开发的命令行工具，用于根据函数名称生成哈希值。该工具可以用于代码分析、函数去重、代码指纹识别等场景。

## 设计目标

1. **高性能**：使用 Rust 语言实现，确保哈希计算的高效性
2. **自定义算法**：实现专用的函数名哈希算法，针对函数名特征优化
3. **易用性**：提供友好的命令行接口
4. **可扩展性**：支持添加新的哈希算法
5. **准确性**：确保相同函数名产生一致的哈希值

## 系统架构

```
┌─────────────────┐
│   CLI Interface │  ← clap 参数解析
└─────────────────┘
         │
┌─────────────────┐
│  Input Parser   │  ← 函数名解析和验证
└─────────────────┘
         │
┌─────────────────┐
│ Hash Generator  │  ← 核心哈希生成逻辑
└─────────────────┘
         │
┌─────────────────┐
│ Hash Algorithms │  ← MD5, SHA-256, SHA-512 等
└─────────────────┘
```

## 核心组件

### 1. CLI Interface (`src/main.rs`)
- 使用 `clap` 库处理命令行参数
- 支持的参数：
  - `--function, -f`: 函数名称
  - `--algorithm, -a`: 哈希算法选择
  - `--output, -o`: 输出格式（hex, base64）
  - `--file`: 从文件读取函数名列表

### 2. Input Parser (`src/parser.rs`)
- 验证函数名格式
- 支持多种编程语言的函数名规范
- 处理特殊字符和编码

### 3. Hash Generator (`src/generator.rs`)
- 核心哈希生成逻辑
- 算法选择和调用
- 输出格式化

### 4. Hash Algorithms (`src/hash/`)
- `src/hash/mod.rs`: 算法注册和管理
- `src/hash/custom.rs`: 自定义函数名哈希算法实现
- `src/hash/traits.rs`: 哈希算法特征定义

## 数据流

1. **输入阶段**：用户通过命令行传入函数名和参数
2. **解析阶段**：解析和验证函数名格式
3. **处理阶段**：选择哈希算法，生成哈希值
4. **输出阶段**：格式化并输出结果

## 接口设计

### 命令行接口

```bash
# 基本用法 - 单个函数哈希
genfunchash -f "func1"

# 批量处理生成 C 数组
genfunchash -i functions.txt -o hash_table.c

# 输出示例
/*[ 0]*/{0x3D1EF464,                             (void *)func1},
/*[ 1]*/{0x3D021EC4,                             (void *)func2},
```

### 配置文件支持

```toml
# genfunchash.toml
[default]
algorithm = "sha256"
output_format = "hex"

[algorithms]
enabled = ["md5", "sha256", "sha512"]
```

## 错误处理

使用 Rust 的 `Result<T, E>` 类型进行错误处理：

- `ParseError`: 函数名解析错误
- `HashError`: 哈希计算错误
- `IoError`: 文件读写错误
- `ConfigError`: 配置文件错误
